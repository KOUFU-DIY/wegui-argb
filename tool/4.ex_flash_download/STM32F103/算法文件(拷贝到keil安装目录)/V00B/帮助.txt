FLM算法文件放到 Keil 安装目录
<Keil 安装目录>\ARM\Flash (例 D:\Keil_v5\ARM\Flash)

适用: STM32F103 + W25Q128 (GD25Q128 等指令兼容的 16MB SPI Flash 也可用)

该算法引脚配置(SPI2):
DI---PB15
CLK---PB13
DO---PB14
CS---PB12

速率 16Mhz (用片内时钟, 不要求板上有晶振)

与 V00A 的区别:
1. 一次下发 2048 字节(V00A 是 256), 烧录更快
2. RAM for Algorithm 的 Size 用默认的 0x1000 即可(V00A 要 0x4000), 设得更大也可以
3. 没接芯片或接线不对时, 一开始就报错
4. 擦除超时放宽到 300 秒(整片擦除需要 40~200 秒)

烧录步骤:
1. 运行 tool\3.bin2c\build_bin.bat, 生成 output\embed\merged_bin.c
2. 打开 flash_download 工程, 编译
3. 第一次使用先检查下载设置(Options for Target - Debug - Settings - Flash Download):
   Programming Algorithm 只保留 WE_STM32F103_W25Q128 (点 Add 添加, 片内 Flash 的算法 Remove 掉)
   RAM for Algorithm: Start 0x20000000  Size 0x1000
   勾选 Erase Sectors / Program / Verify / Reset and Run
4. 点下载(Download), 等待擦除、编程、校验完成

需要自定义实现算法的可自行查看Flash_FLM文件夹下的工程(换引脚改 stm32f103_flash_spi_port.h, 不在 SPI2 上的引脚把 FLASH_SPI_SOFT 改成 1 用软件SPI), 正确编译即可生成算法文件
