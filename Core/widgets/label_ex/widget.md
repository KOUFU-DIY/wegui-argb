# label_ex

## 功能
可旋转、可缩放的高级文字控件，渲染模型与 `img_ex` 类似，但对象本体仍然很轻量。

## 适用场景
- 旋转标题
- 仪表刻度文字
- 呼吸/摆动文字动画
- 需要文字变换效果的页面元素

## 关键 API
- `we_label_ex_obj_init(...)`
- `we_label_ex_set_text(...)`
- `we_label_ex_set_center(...)`
- `we_label_ex_set_transform(...)`
- `we_label_ex_set_color(...)`
- `we_label_ex_set_opacity(...)`

## 可调宏
在 `we_user_config.h` 中可覆盖：
- `WE_CFG_LABEL_EX_MAX_GLYPHS`：单次绘制的字形表容量（栈上每字形 16 字节，默认 32）；首行有墨字形超出部分不渲染

## 事件与行为
- 不处理输入：event_cb 为 NULL，命中测试跳过它，触摸落到背后的控件
- 随容器平移（group / scroll_panel / slideshow）时，`set_pos_cb` 把包围盒和变换中心 `cx/cy` 一起平移
- 常用于动画或装饰性文字

## 注意事项
- 角度单位和 `img_ex` 一致，使用 512 步制
- 缩放单位 `scale_256` 中，`256 = 1.0x`；`set_transform` 传 0 时忽略本次调用
- `cx/cy` 是屏幕变换中心，不是左上角坐标
- 只画首行；文字框 = 首行排版宽度 × 字体行高，伸出文字框左侧或上下的墨迹会被裁掉
- 只保存文字指针；`set_text` 不比较指针，原地改写同一缓冲区后再调用也会重新测量并重绘
- 与 img_ex 同一套采样几何：0°、1.0x 时与普通 label 逐像素一致（墨迹不伸出文字框时），180° 时恰好点对称

## 已完成的毕业优化
- 逆映射步进改为四舍五入并取像素中心采样（原先截断成 4095：偶数宽的文字中心列重复、末列丢失）；步进、采样起点、外接框与 img_ex 共用 `we_xform_steps` / `we_xform_origin` / `we_xform_bbox`，纯 32 位运算
- 外接框四角按半像素精度向外取整（原先放大时文字框右列、底行会被裁掉，如 knob 预览的 2 倍百分比）
- 补上 `set_pos_cb`：放进容器后随容器平移不再错位 / 被裁
- 文字宽度改为首行排版宽度（原先按多行里最宽的一行算，但只画首行，多行文字会偏离中心）
- 每个切片把窗口四角逆映射回文字框，只解析与之相交的字形；上限按字符串顺序计数，画出哪些字不随脏矩形切法变化
- 容器透明度级联后 <= 5 时整段跳过（不再先建字形表）；越界判断改为一条无符号比较
- `set_center` / `set_transform` 值未变直接返回；`set_text` 宽度不变时只重绘原区域；颜色比较用 `we_colour_eq`（GRAY8 下也能去重）
